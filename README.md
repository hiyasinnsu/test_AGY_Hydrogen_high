# STARFALL // NEON BARRAGE

スマホの片手タッチ操作に最適化された、ピュア ES Modules + Canvas 2D + Web Audio API 製の縦スクロール弾幕シューティングゲームです（外部ライブラリ依存ゼロ）。

- **公開 URL (GitHub Pages)**: https://hiyasinnsu.github.io/test_AGY_Hydrogen_high/

## ゲーム概要

- **論理画面サイズ**: `360 x 640`（9:16 縦画面最適化・PC ブラウザでも縦型アーケード筐体風に中央表示）
- **弾幕 & システム**:
  - 極小当たり判定 (`hitboxRadius: 3`) とグレイズ判定 (`grazeRadius: 18`)
  - パワーアップで最大 4 段階に強化されるオート連射ショット
  - ボム発動による敵弾全消去 + 全体ダメージ + 無敵時間
  - 自機狙い・全方位リング・渦巻き・交差弾・加減速弾・予告線付きレーザーなど多彩な弾幕
  - 全 3 ステージ（各ステージ雑魚ウェーブ＋スペルカード付きボス複数フェーズ）
  - 難易度 3 段階 (`EASY` / `NORMAL` / `HARD`)・ハイスコア保存 (`localStorage`)

## 操作方法

### スマートフォン / タブレット
- **移動**: 画面上のどこでもタッチ＆ドラッグすると、指の位置に関係なく自機が**相対移動**します（指で自機や弾が隠れません）。設定からドラッグ感度を調整できます。
- **ボム**: 画面右下の **BOMB** ボタンをタップ（敵弾全消去＋無敵）。
- **低速フォーカス**: 画面左下の **FOCUS** ボタン（または 2 本指タッチ）で移動速度を抑えて精密回避（低速時・画面上部移動時はアイテム自動回収）。
- **ポーズ**: 画面上部のポーズボタンから再開・リスタート・ミュート・タイトル復帰が可能。

### PC（マウス / キーボード）
- **移動**: 矢印キー / `WASD` キー、または画面内のマウスドラッグ（相対移動）
- **低速フォーカス**: `Shift` キー
- **ボム**: `X` キーまたは `Space` キー
- **ポーズ**: `P` キーまたは `Esc` キー

## ローカル起動方法

ES Modules (`type="module"`) を使用しているため、`file://` 直開きではなく静的 HTTP サーバー経由で起動してください。

```bash
# Node.js (npx serve) を使う場合
npx --yes serve .

# Python 3 を使う場合
python -m http.server 8080
```

起動後、ブラウザで `http://localhost:8080`（または表示された URL）にアクセスしてください。

## テスト実行方法

Node.js 標準のテストランナー (`node:test`) を使用しており、`npm install` は不要です。

```bash
npm test
# または
node --test tests/*.test.mjs
```
